# shimmer-fdn-reverb

Companion repository of the submitted DAFx26 paper "Shimmer Reverberation with Nonlinear Feedback Delay Networks."  
Audio examples can be found at [this link](http://research.spa.aalto.fi/publications/papers/dafx26-shimmer/).

This repository contains Python implementations and analysis notebooks used to prototype and evaluate nonlinear and time-varying blocks for shimmer-reverb design. The complete Nonlinear FDN implementation is on [PyFDN](https://artificial-audio.github.io/pyFDN/_static/marimo/notebooks/example_shimmer_fdn.html).

Main contents:
- `src/`: core signal-processing modules (nonlinearities and time variations)
- `test_nonlinearities.ipynb`: notebook for nonlinear response visualization
- `output/`: generated audio examples
